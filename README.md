# 教會服事排班（網頁版）

輸入人員、服事位置、不行日期與限制條件，產出初版服事表並下載 Excel。

**資料只留在你的瀏覽器。** 這個網頁沒有後端，不會上傳任何名單、日期或排班結果，也沒有帳號與追蹤。要備份或換電腦，請用「匯出」下載專案檔（JSON），下次「匯入」回來。

> 目前狀態：Phase 0（骨架）。排班引擎與輸入畫面依 `docs/網頁版規格.md` 的分期陸續接上。

---

## 怎麼用

1. **梯次** — 填梯次起訖日期與聚會在星期幾，按一下產生整梯次的聚會日；選聖餐週是「每月第幾次聚會」，也可以逐週自己改。
2. **服事位置** — 預設帶領會、司琴、音控、招待、聖餐五個位置，可以改名稱、改每週需要幾人、增加或刪除。
3. **人員** — 貼上一整串姓名就能批次建立，再勾每個人可以擔任哪些位置。
4. **不行日期**（可跳過）— 直接點日期，或把 LINE 上收集到的訊息交給你自己的 AI 整理（網頁會提供一段可複製的指示），再把結果貼回來。
5. **限制條件**（可跳過）— 固定搭檔、服事間隔、每月上限、輪替配對這些規則。不設也排得出來。
6. **產生班表** — 看結果、看警告、下載 Excel 或 CSV。

最短路徑是 1 → 2 → 3 → 產生，大約 5 分鐘就能看到第一版。

## 開發

```bash
npm install
npm run dev        # 本機開發
npm test           # 測試（含 parity 測試）
npm run build      # 產出 dist/
```

推到預設分支會由 GitHub Actions 自動發布到 GitHub Pages。

### parity 測試

`tests/fixtures/` 裡的匿名 fixture 與 golden 班表，是用舊版 Python 引擎產生的行為基準，
排班引擎移植到 TypeScript 後必須逐格重現同樣的結果。產生指令在私有的上層資料夾
（`tools/parity/make_fixture.py`），fixture 裡的姓名一律是 `M01`…`M28` 代號。

### 文件

架構、資料格式、限制條件型別與分期驗收條件都在 `docs/網頁版規格.md`（上層資料夾）。
